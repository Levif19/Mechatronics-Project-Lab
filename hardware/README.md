# Hardware Design - 7-DOF Robotic Arm

This directory contains physical design files, CAD models, and 3D printable components for the custom 7-DOF robotic arm.

## ⚙️ Hardware Specifications

- **3D-Printed Components:** Includes high-torque 3D-printed STLs (such as compound planetary gearboxes) engineered for high power density and modularity.
- **Target Printer:** Designed and optimized for printing on a **Creality K1** 3D printer (or equivalent FDM printer) using high-strength filaments (PETG/ABS/ASA).
- **CAD Formats:** Tracks `.stl`, `.step`, `.f3d`, and `.3mf` files via Git LFS.

## 📂 Subdirectories

- [`assemblies/`](assemblies/): Full CAD assembly files and exploded view models.
- [`parts_printed/`](parts_printed/): Individual printable STL models for planetary gearboxes, joint housings, structural links, and end-effector mounts.

# Electronics & Wiring

This directory contains electrical schematics, power distribution diagrams, and wiring harness specifications for the 7-DOF robotic arm.

## ⚡ Specifications

- **Power Supply:** Main DC power bus for stepper drivers and high-torque actuation.
- **Microcontroller & Drivers:** Wiring configurations for Arduino Mega with RAMPS 1.6 shield.

## 📂 Subdirectories

- [`schematics/`](schematics/): Circuit schematics and PCB layout files.
- [`wiring/`](wiring/): Wiring diagrams, pinout charts, and cable harness documentation.

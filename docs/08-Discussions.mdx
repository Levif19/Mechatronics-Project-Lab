# Discussions & Lessons Learned

Building a highly integrated robotic arm rarely goes exactly according to the initial CAD plan. This section serves as a reflection of the build process.

## Challenges Faced
* **Slip Ring Constraints:** Fitting 28 wires through the base required significant redesigns of the Joint 0 hollow shaft.
* **Torque vs. Weight:** Balancing the heavy NEMA 23 base motors against the lever-arm effect of the distal NEMA 17s.
* **EMI Crosstalk:** Initial tests showed jitter on the logic lines due to proximity to the stepper power phases.

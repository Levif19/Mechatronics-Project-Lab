# User Interface (UI) & App Development

## 1. Why a Dedicated App?
While G-code terminals are great for debugging, a 7-DoF arm requires an intuitive control scheme. A dedicated app allows for visual "Digital Twin" manipulation, real-time telemetry monitoring (temperature and current draw), and macro execution without writing raw code.

## 2. UI Design
The interface was designed with a "dark mode, industrial glass-cockpit" aesthetic. 
* **Control Panel:** Sliders for manual joint overrides.
* **Telemetry:** Live graphs reading data from the Octopus shunt resistors.
